Mise à jour du serveur Bourselle

Étape 1 : copie le code avec le bouton.

  1. Ouvre l'éditeur Cloudflare.
  2. Touche le code, puis touche à nouveau le curseur : choisis Tout sélectionner, puis touche la sélection et choisis Coller.
  3. Vérifie que la dernière ligne est export default WORKER;, puis appuie sur Deploy.

Si le bouton ne copie pas : touche le cadre ci-dessous, « Tout sélectionner », « Copier ».
